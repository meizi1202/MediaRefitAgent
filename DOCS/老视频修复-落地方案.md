# 老视频修复技能 - 落地方案

## Context

MediaRefitAgent 需要新增"老视频修复"技能，支持通过自然语言指令对老旧视频进行专业级修复和增强。需求来源于两个文档：
- **需求文档**：定义功能清单（去噪、去抖动、色彩、对比度、划痕、闪烁、补帧、超分）和 API 接口设计
- **开源方案文档**：提供算法选型（RealBasicVSR、ProPainter、FlashVSR 等）和架构参考

核心业务链路：`视频输入 → [ProPainter划痕霉斑去除] → 时序视频复原 RealBasicVSR/RVRT/FlashVSR → ffmpeg编码输出`

## 架构设计

```
HTTP接口层 (FastAPI)
    ├── /api/restore          # 同步REST接口
    ├── /api/restore-stream   # SSE流式接口
    └── /api/capabilities     # 能力查询
            │
            ▼
    异步任务层 (Background Tasks / Celery)
    长视频处理不能阻塞HTTP
            │
            ▼
    【修复流水线 - 可配置步骤】
    ├─[可选] ProPainter        划痕霉斑去除
    ├─[必选] 时序视频复原       RealBasicVSR / RVRT / FlashVSR
    └─[可选] CodeFormer        人脸局部增强
            │
            ▼
    FFmpeg工具模块 - 帧序列合成mp4、CRF编码、音频拷贝
```

## 核心数据模型

```python
# video/restoration.py

class RestorationPreset(str, Enum):
    BASIC = "basic"        # 去噪、去抖动、色彩、对比度
    FILM = "film"          # 基础 + 划痕、闪烁
    ENHANCED = "enhanced"  # 完整 + 补帧、超分
    CUSTOM = "custom"

@dataclass(frozen=True)
class RestorationOptions:
    denoise: bool = False
    denoise_level: str = "medium"
    deblur: bool = False
    color_correct: bool = False
    saturation: int = 0
    contrast_enhance: bool = False
    scratch_remove: bool = False
    flicker_remove: bool = False
    interpolate: bool = False
    target_fps: int = 60
    super_resolution: bool = False
    scale_factor: int = 2

@dataclass(frozen=True)
class RestorationRequest:
    input_path: str
    output_path: str
    preset: RestorationPreset = RestorationPreset.BASIC
    options: RestorationOptions = field(default_factory=RestorationOptions)
    progress_callback: Optional[callable] = None

@dataclass(frozen=True)
class RestorationResult:
    success: bool
    input_path: str
    output_path: str
    preset: str
    stages: list[RestorationStageResult]
    total_duration: float
    output_size: int
```

## 实现优先级 (M1-M5)

> **当前环境：CPU only**，优先实现 FFmpeg 原生方案；GPU 方案预留扩展接口。

| 阶段 | 内容 | 优先级 | CPU 方案 | GPU 升级后 |
|------|------|--------|----------|------------|
| **M1** | 基础修复套餐 | **P0** | FFmpeg `hqdn3d` 去噪、`eq` 色彩/`unsharp` 锐化 | 自动切换到 DnCNN AI 去噪 |
| **M2** | 胶片修复 | **P1** | FFmpeg `descratch` 划痕、`fade` 闪烁 | 升级到 ProPainter |
| **M3** | 补帧功能 | **P1** | FFmpeg `minterpolate` | 升级到 RIFE AI 补帧 |
| **M4** | 超分辨率 | **P2** | FFmpeg `scale` + lanczos | 升级到 Real-ESRGAN AI 超分 |
| **M5** | AI增强模块 | **P3** | ❌ 不支持（需GPU） | RealBasicVSR、ProPainter、RIFE、DnCNN、Real-ESRGAN、Celery |

## 开源代码使用方案

### 1. 底层算法源码（无 GUI，纯 Python 推理）

| 算法 | 仓库地址 | 用途 | 集成方式 |
|------|----------|------|----------|
| **RealBasicVSR** | https://github.com/ckkelvinchan/RealBasicVSR | 时序视频超分+降噪，x4，VHS老录像友好 | 克隆仓库，封装推理接口；权重从 ModelScope 下载 |
| **ProPainter** | https://github.com/sczhou/ProPainter | 视频修复，消除划痕、污渍；需放超分前 | 克隆仓库，封装 inpainting 接口 |
| **RVRT** | https://github.com/JingyunLiang/RVRT | 重度噪声、运动模糊；16G+ 显存 | 备选方案，同上 |
| **FlashVSR** | https://github.com/OpenImagingLab/FlashVSR | CVPR2026，流式处理，显存友好 | 备选方案，同上 |
| **SeedVR2** | https://github.com/ByteDance/Seed/SeedVR | 生成式DiT，重度损毁；20-24G显存 | 可选高级能力 |

### 2. 中间层工具箱

| 工具箱 | 地址 | 用途 |
|--------|------|------|
| **BasicSR** | https://github.com/xinntao/BasicSR | 视频/图像复原推理框架；RealBasicVSR/BasicVSR++/SwinIR/Real-ESRGAN 底层；提供权重加载、tile分块推理、帧读写工具 |

### 3. 集成策略

**方案选择**：采用"克隆仓库 + 封装推理"方式
- 克隆上述仓库到 `thirdparty/` 目录
- 编写封装层调用官方推理脚本，不直接修改源码
- 模型权重通过官方渠道下载（HuggingFace/ModelScope/GitHub Release）

### 6. 硬件资源需求

| 配置级别 | CPU | 内存 | 显存 | 适用场景 |
|----------|-----|------|------|----------|
| **最低** | 4核 | 4GB | 无 | 仅 FFmpeg 基础滤镜，AI功能不可用 |
| **推荐** | 6核 | 8GB | 4GB NVIDIA GPU | FFmpeg + AI去噪/补帧/超分 |
| **最佳** | 8核+ | 16GB+ | 8GB+ NVIDIA GPU | 全功能AI增强，高速处理 |

**各功能资源需求**：

| 功能 | CPU模式 | GPU模式 |
|------|---------|---------|
| 去噪 (FFmpeg) | 2GB RAM | - |
| 去噪 (DnCNN) | 8GB RAM, 4核+ | 4GB+ GPU |
| 色彩/对比度 | 2GB RAM | - |
| 划痕/闪烁修复 | 4GB RAM | - |
| 补帧 (FFmpeg) | 4GB RAM | - |
| 补帧 (RIFE) | 需GPU | 6GB+ GPU |
| 超分 (lanczos) | 2GB RAM | - |
| 超分 (ESRGAN) | 需GPU | 4GB+ GPU |
| 时序复原 (RealBasicVSR) | 需GPU | 6GB+ GPU |
| 划痕修复 (ProPainter) | 需GPU，显存高 | 16GB+ GPU |

### CPU 模式推荐配置

- **基础修复（去噪/色彩/对比度/闪烁）**：FFmpeg 滤镜，实时处理
- **补帧**：FFmpeg `minterpolate`，预处理后播放流畅度提升
- **超分**：FFmpeg `scale`，仅做分辨率调整

### 预估处理时间（1分钟1080p视频）

| 操作 | CPU (无GPU) | GPU (4GB+) |
|------|-------------|------------|
| FFmpeg 基础滤镜 | ~30秒 | ~30秒 |
| AI 去噪 (DnCNN) | ~10-20分钟 | ~1-2分钟 |
| 补帧 (minterpolate) | ~5-10分钟 | ~5分钟 |
| AI 超分 (ESRGAN) | 不推荐 | ~5-10分钟 |

## 关键扩展点

### 1. video/processor.py 扩展
新增函数遵循 `run_ffmpeg()` + `progress_callback` 模式：
- `denoise_video(input, output, level, progress_callback)`
- `color_correct_video(input, output, saturation, contrast, progress_callback)`
- `deblur_video(input, output, level, progress_callback)`
- `remove_scratch(input, output, level, progress_callback)`
- `remove_flicker(input, output, level, progress_callback)`
- `interpolate_frames(input, output, target_fps, use_ai, progress_callback)`
- `super_resolve_video(input, output, scale, use_ai, progress_callback)`

### 2. ml/restoration/ AI模型封装
遵循三层封装模式(数据层/结果层/模型层)和懒加载：
- `BaseRestorationModel` - 抽象基类，定义模型接口
- `Denoiser` - DnCNN去噪，~50MB
- `RIFEInterpolator` - RIFE补帧，~400MB
- `RealESRGAN` - Real-ESRGAN超分，~65MB
- `RealBasicVSRRestorer` - RealBasicVSR时序复原

### 3. api/fastapi_app.py 扩展
遵循现有SSE流式响应模式：
- `POST /api/restore` - 同步修复接口
- `POST /api/restore-stream` - SSE流式进度接口

### 4. agent/langchain_agent.py 扩展
- `parse_intent()` 中 `tool_prompt` 添加 restore 识别（"修复"、"老视频"、"老电影" → "restore"）
- 添加 `parse_restore_params()` 解析修复参数（preset、options）
- 返回字典增加 `restoration_preset`、`restoration_options` 等字段

### 5. agent/video_agent.py 扩展
- `VideoAgentState` 增加 `restoration_preset`、`restoration_options`、`restoration_result` 字段
- 新增 `execute_restore` 节点函数，调用 `RestorationPipeline`
- `should_proceed` 增加 `current_feature == "restore"` 分支

## 验证方式

1. **单元测试**：为每个FFmpeg滤镜函数和AI模型编写pytest测试
2. **集成测试**：使用样例老视频调用 `/api/restore` 验证完整流水线
3. **SSE测试**：调用 `/api/restore-stream` 验证进度推送
4. **CLI测试**：`python -m agent.cli --text "修复老电影" --video input.mp4`
5. **多轮对话测试**：Agent中连续对话调整修复参数
