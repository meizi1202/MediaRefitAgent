### 🎬 智能缩编

包含两种策略：内容缩编和智能压缩

| 策略 | 说明 |
|------|------|
| **内容缩编** | Whisper语音识别+音频能量分析，自动选择高光片段到目标时长 |
| **智能压缩** | FFmpeg重编码，压缩视频文件大小 |

#### 内容缩编处理流程

| 阶段 | 技术 | 说明 |
|------|------|------|
| 1 | Whisper ASR | 语音识别，获取字幕和时间轴 |
| 2 | 音频能量分析 | 计算每段RMS能量值 |
| 3 | 能量评分排序 | 按 `max(0, min(1, (energy_db + 60) / 60))` 归一化评分 |
| 4 | 智能选段 | 优先选择高分片段达到目标时长 |

## 资源配置说明

### 🤖 大模型（LLM）资源配置

大模型承担意图理解、内容分析、情绪识别等核心AI能力，支持两种调用模式：

#### 模式一：云端调用（厂商API）

| 方案 | 说明 | 所需资源 |
|------|------|----------|
| **MinMax API** | 调用厂商云端大模型 | 仅需网络访问，无需本地GPU |
| **OpenAI API** | 调用 OpenAI 云端服务 | 仅需网络访问，无需本地GPU |
| **Azure OpenAI** | 企业级云端调用 | 仅需网络访问，无需本地GPU |

**优点：** 无需 GPU 资源，按需付费，弹性扩展
**缺点：** 依赖网络，需要 API 费用

---

#### 模式二：本地部署

如需私有化部署或降低 API 成本，可本地部署大模型：

| 模型 | 参数量 | 显存需求 | 推荐GPU | 说明 |
|------|--------|----------|---------|------|
| **Qwen2-7B** | 7B | 8GB+ | RTX 3060 / 昇腾910B | 轻量级，性价比高 |
| **Qwen2-14B** | 14B | 16GB+ | RTX 4090 / 昇腾910B | 精度更高 |
| **Qwen2-72B** | 72B | 48GB+ | RTX 3090 x2 (NVIDIA) / 昇腾910B x2 | 旗舰级性能 |
| **Yi-34B** | 34B | 24GB+ | RTX 3090 / 昇腾910B | 中英双语优化 |
| **ChatGLM3-6B** | 6B | 6GB+ | RTX 3060 / 昇腾910B | 国产优化 |

**本地部署优点：**
- 数据不出本地，安全性高
- 长期使用成本可控
- 无网络依赖

**本地部署所需资源：**
- GPU: 昇腾910B / RTX 3060 12GB+（根据模型大小选择）
- CPU: 8核+
- 内存: 32GB+
- 存储: 100GB+ SSD（模型文件）
- 系统: Ubuntu 22.04 / CUDA 11.8+
