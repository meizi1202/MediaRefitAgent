# 前端开发设计 - 剪映对接界面

## Context

为 MediaRefitAgent 前端添加剪映草稿对接功能，允许用户：
1. 创建剪映草稿
2. 添加视频/音频/字幕
3. 保存草稿并获取 draft_url
4. 在剪映客户端中打开编辑

### Step 2: 添加 API 函数 ([api/index.ts](frontend/src/api/index.ts))

在 `api` 对象中添加（第262行前）：
```typescript
// ========== 剪映对接 ==========
async jianyingCreateDraft(width: number, height: number): Promise<any> {
  return fetchJson(`${API_BASE}/jianying/create_draft`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ width, height }),
  });
},

async jianyingAddVideos(formData: FormData): Promise<any> {
  const resp = await fetch(`${API_BASE}/jianying/add_videos`, { method: 'POST', body: formData });
  return resp.json();
},

async jianyingAddAudios(formData: FormData): Promise<any> {
  const resp = await fetch(`${API_BASE}/jianying/add_audios`, { method: 'POST', body: formData });
  return resp.json();
},

async jianyingAddCaptions(formData: FormData): Promise<any> {
  const resp = await fetch(`${API_BASE}/jianying/add_captions`, { method: 'POST', body: formData });
  return resp.json();
},

async jianyingSaveDraft(draftUrl: string): Promise<any> {
  return fetchJson(`${API_BASE}/jianying/save_draft`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ draft_url: draftUrl }),
  });
},

async jianyingGetDraft(draftId: string): Promise<any> {
  return fetchJson(`${API_BASE}/jianying/get_draft?draft_id=${draftId}`);
},
```

### Step 3: 创建 JianyingPanel ([frontend/src/components/panels/JianyingPanel.vue](frontend/src/components/panels/JianyingPanel.vue))

新建面板，参考 `OrientPanel.vue` 模式：
- 模板：`<Transition name="slide-up"><div class="panel" v-if="visible">...</div></Transition>`
- 脚本：使用 `ref` 管理本地状态，`watch` 同步到 store
- 样式：参考现有面板的深色主题样式

**核心功能**：
1. **创建草稿** - 宽高输入（默认 1080x1920 竖屏 / 1920x1080 横屏）
2. **添加视频** - 文件上传或 URL 输入，支持多视频
3. **添加音频** - 文件上传或 URL 输入
4. **添加字幕** - 文本输入 + 时间范围
5. **保存草稿** - 调用 save_draft API
6. **复制 draft_url** - 一键复制到剪映客户端打开

## 验证计划

1. 启动后端 `python -m api.fastapi_app`
2. 启动前端 `npm run dev`
3. 访问 http://localhost:8083
4. 点击"剪映对接"功能标签
5. 输入宽高（默认竖屏 1080x1920）
6. 点击"创建草稿"按钮
7. 添加视频文件或输入 URL
8. 点击"保存草稿"
9. 复制 draft_url 到剪映客户端打开
