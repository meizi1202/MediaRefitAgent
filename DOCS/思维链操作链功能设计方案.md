# 思维链操作链功能设计方案

## 1. 背景与目标

### 1.1 现状问题

当前系统每个操作独立执行，用户需要分多次请求：

```
用户: "把视频修剪到30秒"
系统: [执行修剪] → 完成

用户: "再转成竖屏"
系统: [执行转换] → 完成

用户: "最后加个BGM"
系统: [执行配乐] → 完成
```

### 1.2 目标

支持一次性描述多个操作步骤，系统按顺序自动执行：

```
用户: "先把视频修剪到前30秒，然后转成竖屏，最后加上欢快的BGM"
系统: [解析操作链] → [执行修剪] → [执行转换] → [执行配乐] → 完成
```

## 2. 现状分析

### 2.1 当前架构

```
LangGraph StateGraph
├── analyze_intent      # 解析用户意图（单次操作）
├── execute_transform   # 横竖屏转换
├── execute_trim       # 视频修剪
├── execute_compress   # 视频压缩
├── execute_concat     # 视频拼接
├── execute_condense   # 智能缩编
├── execute_restore    # 老视频修复
├── execute_editor     # 智能剪辑（包含BGM）
└── confirm_complete   # 结束
```

**关键特征**：
- 每次只执行一个操作
- 执行完成后直接到 `confirm_complete`
- `temp_video_path` 记录当前视频路径，但执行完后不自动流转到下一步

### 2.2 关键文件

| 文件 | 职责 |
|------|------|
| `backend/agent/types.py` | 状态类型定义 `VideoAgentState` |
| `backend/agent/video_agent.py` | LangGraph 图构建 `create_video_agent_graph()` |

## 3. 方案设计

### 3.1 核心思路

引入**操作队列**机制：

1. **解析阶段**：从用户输入中识别多个操作步骤，生成有序操作队列
2. **执行阶段**：按队列顺序执行每个操作，上一步输出作为下一步输入
3. **进度跟踪**：跟踪当前执行到第几步，整体进度如何

### 3.2 数据结构扩展

#### 3.2.1 新增 OperationStep 类型

```python
class OperationStep(TypedDict):
    """单个操作步骤"""
    step_id: str                           # 步骤唯一标识，如 "step_1"
    feature: str                           # 操作类型: convert/trim/compress/bgm/...
    step_name: str                         # 步骤中文名称（展示用）
    params: dict                           # 该步骤的参数
    status: str                            # pending/running/completed/failed
    started_at: Optional[str]              # 开始时间（ISO格式）
    completed_at: Optional[str]            # 完成时间（ISO格式）
    duration_seconds: Optional[float]      # 执行时长（秒）
    result: Optional[dict]                 # 执行结果
    error: Optional[str]                   # 错误信息
```

**执行顺序**：线性串联，上一步输出自动作为下一步输入。

> **注**：如需更复杂的分支操作（如"对原始视频和中间结果分别操作"），可后续迭代扩展。

#### 3.2.2 VideoAgentState 扩展字段

```python
    current_step_index: int                # 当前执行到的步骤索引
```


### 3.3 两种操作模式

系统同时支持两种操作模式：

#### 模式1：操作链（一次性描述）

用户一次性描述多个操作，系统自动解析并顺序执行：

```
用户: "先把视频修剪到前30秒，然后转成竖屏，最后加上欢快的BGM"
系统: [解析操作链] → [执行修剪] → [执行转换] → [执行配乐] → 完成
```

#### 模式2：逐步引导（执行一步问一步）

每步执行完成后，系统根据上下文**智能提示**可能的下一步：

```
用户: "先修剪30秒"
系统: [执行修剪] → "检测到视频是横屏格式，要转换为竖屏吗？"

用户: "转成竖屏"
系统: [执行转换] → "视频时长3分钟，是否需要添加背景音乐？"

用户: "加个欢快的BGM"
系统: [执行配乐] → 完成
```

**智能提示逻辑**：

| 当前状态 | 可能的智能提示 |
|---------|--------------|
| 刚完成 trim | 检测到横屏 → 询问是否转换竖屏 |
| 刚完成 convert | 询问是否添加BGM/字幕/封面 |
| 刚完成 compress | 询问是否需要其他处理 |
| 刚完成任何操作 | "还需要其他处理吗？"（通用兜底）|

#### 3.4.2 execute_feature 统一执行接口

```python
def execute_feature(feature: str, input_path: str, params: dict) -> dict:
    """统一执行接口，调用现有执行器"""

    # 映射到现有执行器
    executor_map = {
        "trim": execute_trim,
        "convert": execute_transform,
        "compress": execute_compress,
        "concat": execute_concat,
        "condense": execute_condense,
        "restore": execute_restore,
        "editor": execute_editor,
        "info": execute_info,
    }

    # 编辑器子模式
    editor_sub_modes = ["bgm", "subtitle", "transition", "cover", "title-package", "filter", "tts"]
    if feature.startswith("editor/"):
        sub_mode = feature.split("/")[1]
        params["editor_mode"] = sub_mode
        feature = "editor"

    executor = executor_map.get(feature)
    if not executor:
        return {"success": False, "error": f"未知操作类型: {feature}"}

    # 调用执行器（复用现有逻辑）
    state = VideoAgentState(
        video_path=input_path,
        temp_video_path=input_path,
        **params
    )
    result_state = executor(state)

    # 提取结果
    result_key = f"{feature}_result"
    if result_key in result_state:
        return result_state[result_key]
    elif "error" in result_state:
        return {"success": False, "error": result_state["error"]}
    else:
        return {"success": True, "output_path": result_state.get("temp_video_path")}
```

#### 3.4.3 参数校验与缺失处理

```python
def validate_operation_params(feature: str, params: dict) -> tuple[bool, Optional[str]]:
    """校验操作参数是否完整

    返回: (是否有效, 错误信息)
    """
    required_params = {
        "trim": ["start_time", "end_time"],
        "convert": ["target_orientation"],
        "compress": ["compression_level"],
        "editor": ["editor_mode"],
    }

    required = required_params.get(feature, [])
    missing = [p for p in required if p not in params or params[p] is None]

    if missing:
        return False, f"缺少参数: {', '.join(missing)}"
    return True, None
```

解析示例：

| 用户输入 | 解析结果 |
|---------|---------|
| `"转成竖屏"` | 单操作：`[{"feature": "convert", ...}]` |
| `"先裁剪30秒，再转竖屏"` | 两步链：`[{"feature": "trim", ...}, {"feature": "convert", ...}]` |
| `"裁剪到30秒，然后转竖屏，最后加BGM"` | 三步链：`[{"feature": "trim", ...}, {"feature": "convert", ...}, {"feature": "editor/bgm", ...}]` |

### 3.4 执行流程改造

#### 3.4.1 新增节点

| 节点 | 职责 |
|------|------|
| `analyze_chain` | 解析操作链，判断是单操作还是多操作链 |
| `execute_chain_step` | 执行当前步骤 |
| `chain_router` | 判断是否还有下一步 |
| `handle_chain_complete` | 操作链完成处理 |

#### 3.4.2 流程对比

**当前流程（单操作）**：
```
analyze_intent → execute_xxx → confirm_complete → END
```

**新流程（操作链）**：
```
analyze_chain → execute_chain_step → chain_router
                                       ↓ (还有下一步)
                                  execute_chain_step → ...
                                       ↓ (完成)
                              handle_chain_complete → END
```

#### 3.4.3 execute_chain_step 执行逻辑

```python
def execute_chain_step(state: VideoAgentState) -> VideoAgentState:
    """执行操作链中的单个步骤"""
    chain = state.get("operation_chain", [])
    current_idx = state.get("current_step_index", 0)

    if current_idx >= len(chain):
        state["current_step"] = "handle_chain_complete"
        return state

    current_step = chain[current_idx]
    current_step["status"] = "running"

    # 获取输入视频路径
    if current_idx == 0:
        input_path = state.get("temp_video_path") or state.get("video_path")
    else:
        prev_step = chain[current_idx - 1]
        input_path = prev_step["result"].get("output_path")

    if not input_path:
        current_step["status"] = "failed"
        current_step["error"] = "输入视频不存在"
        state["chain_status"] = "failed"
        state["current_step"] = "handle_chain_complete"
        return state

    # 调用对应执行器
    feature = current_step["feature"]
    params = current_step["params"]
    result = execute_feature(feature, input_path, params)

    # 保存结果
    current_step["result"] = result
    current_step["status"] = "completed" if result.success else "failed"

    if result.success:
        # 更新 temp_video_path 供下一步使用
        state["temp_video_path"] = result.output_path
        state["current_step_index"] = current_idx + 1
    else:
        state["error"] = result.error
        state["chain_status"] = "failed"
        state["current_step"] = "handle_chain_complete"

    return state
```

#### 3.4.4 handle_chain_complete 节点

操作链完成后，除了汇总结果外，还可根据配置决定是否发送智能提示：

```python
def generate_smart_suggestion(state: VideoAgentState, last_feature: str) -> str:
    """根据上下文生成智能提示"""
    suggestions = {
        "trim": "检测到视频是横屏格式，要转换为竖屏吗？",
        "convert": "视频时长较长，是否需要压缩或添加背景音乐？",
        "compress": "还需要其他处理吗？",
        "editor/bgm": "要生成封面图吗？",
    }
    return suggestions.get(last_feature, "还需要其他处理吗？")
```

**智能提示配置**（`.env` 或 API 参数）：

| 配置项 | 值 | 行为 |
|-------|-----|------|
| `SMART_SUGGESTION_ENABLED` | `true`（默认） | 操作完成后发送智能提示 |
| `SMART_SUGGESTION_ENABLED` | `false` | 操作完成后只显示"完成"，不主动提示 |

#### 3.4.5 chain_router 条件边

```python
def chain_router(state: VideoAgentState) -> str:
    """判断操作链是否继续执行"""
    chain = state.get("operation_chain", [])
    current_idx = state.get("current_step_index", 0)
    chain_status = state.get("chain_status")

    if chain_status == "failed":
        return "handle_chain_complete"

    if current_idx < len(chain):
        return "execute_chain_step"

    return "handle_chain_complete"
```

### 3.5 错误处理策略

**停止执行，保留已完成结果**：

1. 步骤执行失败时，设置 `chain_status = "failed"`
2. 停止后续步骤执行
3. 保留已完成步骤的结果
4. 生成汇总报告，告知用户哪个步骤失败及原因

#### 3.7.1 操作链临时文件

操作链执行过程中会产生多个中间文件：

```

    ↓ step_1 trim
临时文件: video_trimmed_xxx.mp4

    ↓ step_3 bgm
最终输出: video_final_with_bgm_xxx.mp4
```

#### 3.7.2 临时文件清理策略

| 场景 | 处理方式 |
|------|---------|
| 操作链成功完成 | 只保留最终输出文件，删除所有中间临时文件 |
| 操作链中途失败 | 保留已完成步骤的输出文件，删除未执行步骤的输入文件 |
| 用户主动取消 | 删除所有临时文件，只保留用户原始上传视频 |
| 会话超时/异常 | 保留已完成步骤的输出文件 |

```python
def cleanup_chain_temp_files(chain: list[OperationStep], current_idx: int):
    """清理操作链临时文件"""
    for i, step in enumerate(chain):
        if i < current_idx and step.get("result", {}).get("output_path"):
            # 已完成步骤的输出可能有用，保留（由最终清理决定）
            pass

        # 未执行步骤不产生文件，无需清理

    # 会话结束时统一清理中间文件，只保留最终输出
```

### 3.8 与传统流程的兼容

#### 3.8.1 单操作向后兼容

```python
def analyze_chain(state: VideoAgentState) -> VideoAgentState:
    """解析操作链入口"""

    user_input = state.get("new_user_input") or state.get("user_input")

    # 尝试解析为操作链
    chain = parse_operation_chain(user_input)

    if len(chain) == 1:
        # 单操作：复用现有逻辑
        state["operation_mode"] = "single"
        state["current_feature"] = chain[0]["feature"]
        state.update(chain[0]["params"])
        state["all_params_provided"] = check_params_provided(state)
        state["current_step"] = FEATURE_TO_STEP.get(state["current_feature"])
    else:
        # 操作链
        state["operation_mode"] = "chain"
        state["operation_chain"] = chain
        state["current_step_index"] = 0
        state["chain_status"] = "running"
        state["current_step"] = "execute_chain_step"

    return state
```

#### 3.8.2 操作链完成后的衔接

```python
def handle_chain_complete(state: VideoAgentState) -> VideoAgentState:
    """操作链完成处理"""

    chain = state.get("operation_chain", [])
    total_steps = len(chain)
    completed_steps = sum(1 for s in chain if s["status"] == "completed")
    failed_step = next((i for i, s in enumerate(chain) if s["status"] == "failed"), None)

    # 生成汇总消息
    summary = f"操作链完成！\n\n共 {total_steps} 个步骤，{completed_steps} 个已完成"
    if failed_step:
        summary += f"\n第 {failed_step + 1} 步失败: {chain[failed_step].get('error')}"

    _append_message(state, "assistant", summary)

    # 如果启用了智能提示，添加建议
    if SMART_SUGGESTION_ENABLED and not failed_step:
        last_feature = chain[-1]["feature"]
        suggestion = generate_smart_suggestion(state, last_feature)
        _append_message(state, "assistant", suggestion)

    # 同步到现有状态（兼容现有 confirm_complete 逻辑）
    state["current_step"] = "confirm_complete"
    state["messages"] = state.get("messages", [])

    # 触发最终清理（删除中间临时文件）
    cleanup_chain_temp_files(chain, total_steps)

    return state
```
