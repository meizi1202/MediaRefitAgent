## 2. 主流开源项目

### 2.1 FunClip — 阿里达摩院

| 属性 | 说明 |
|------|------|
| **GitHub** | https://github.com/alibaba-damo-academy/FunClip |
| **开发方** | 阿里巴巴达摩院 |
| **Star** | 较高（阿里重点项目） |
| **技术栈** | Python + Gradio + FunASR |
| **定位** | **智能选段工具**（内容缩编） |
| **许可证** | Apache 2.0 |

#### 核心能力

| 功能 | 说明 |
|------|------|
| **语音识别** | FunASR Paraformer/Fun-ASR-Nano/SenseVoice |
| **智能选段** | LLM 分析字幕选出关键片段 |
| **字幕生成** | SRT 格式，带字符级时间戳 |
| **视频裁剪** | FFmpeg 精确裁剪拼接 |

> ⚠️ **注意**：FunClip 本质是**精彩片段提取工具**，擅长 ASR + LLM 智能选段。它不包括智能转场、BGM 配乐、配音等功能，更接近"智能缩编"而非"智能剪辑"。

#### 技术架构

```
输入视频 → ASR 语音识别 → 生成字幕 → LLM 智能分析 → FFmpeg 剪接 → 输出
              ↓
         本地 GPU/CPU              API 调用（MiniMax/Qwen/GPT）
```

#### ASR 模型对比

| 模型 | 模型 ID | 大小 | 精度 | CPU 兼容性 |
|------|---------|------|------|------------|
| **Paraformer-Large** | `iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch` | ~1GB | 最高 | ⚠️ 较慢 |
| **Fun-ASR-Nano** | `FunAudioLLM/Fun-ASR-Nano-2512` | ~500MB | 高 | ✅ 良好 |
| **SenseVoice** | `FunAudioLLM/SenseVoiceSmall` | ~400MB | 高 | ✅ 良好 |

#### LLM 支持

| 模型 | 调用方式 | 说明 |
|------|----------|------|
| **MiniMax** | OpenAI 兼容 | ✅ **已支持**，项目可用 |
| **Qwen** | DashScope | 阿里云百炼 |
| **GPT-4** | OpenAI | 需 API Key |

#### 项目状态

> ✅ **已在 MediaRefitAgent 中集成**
> - FunClip 源码已下载至 `FunClip/` 目录
> - 调度层已实现于 `video/condenser.py`
> - 采用 Whisper ASR 作为替代方案（Windows 验证通过）
> - 属于**内容缩编**能力，与智能剪辑的完整包装能力有区别

## 6. 硬件与模型配置方案

### 6.1 视频智能剪辑完整能力所需模型

完整的视频智能剪辑需要以下模型配合工作：

| 模型 | 用途 | 模型选型 | 模型大小 | 推理方式 |
|------|------|----------|----------|----------|
| **ASR 语音识别** | 音频→字幕 | Whisper Base / FunASR | ~140MB / ~500MB | 本地 |
| **目标检测/裁剪** | 主体检测、智能裁剪 | YOLOv8 | ~50MB | 本地 |
| **情感分类** | 情绪识别（配乐匹配） | EmoBERTa | ~400MB | 本地 |
| **语音合成** | 配音/旁白 | CosyVoice / VITS | ~200MB | 本地 |
| **字幕后处理** | 去口癖 | 规则+LLM | - | API 调用 |
| **智能选段** | LLM 分析选出精彩片段 | MiniMax / Qwen | - | API 调用 |
| **脚本生成** | AI 生成短视频脚本 | MiniMax / GPT | - | API 调用 |

### 6.2 硬件资源配置

#### 配置对比

| 配置 | CPU | 内存 | GPU | 适用场景 |
|------|-----|------|-----|----------|
| **最低** | 4核 | 8GB | 无 | 基础缩编（FFmpeg + Whisper CPU） |
| **推荐** | 8核 | 16GB | 4GB NVIDIA | 完整智能剪辑（YOLO + 实时处理） |
| **最佳** | 16核 | 32GB | 8GB+ NVIDIA | 高速 AI 剪辑、多并发 |

### 6.4 各功能模块模型依赖

#### 精彩片段识别（Highlight Detection）

```
输入视频 → FFmpeg 提取帧 → YOLOv8 检测人脸/物体
                          → 音频能量分析（Whisper）
                          → 动作强度分析（帧差分）
                          → 多维度评分 → 输出精彩片段
```

**所需模型**：YOLOv8、Whisper
**硬件**：CPU 8核 / GPU 4GB（加速用）

#### 智能裁剪（Smart Crop）

```
采样帧（10-20帧） → YOLOv8 检测主体
                   → 合并检测框计算中心点
                   → 根据目标比例计算裁剪窗口
                   → FFmpeg crop 逐帧裁剪
```

**所需模型**：YOLOv8
**硬件**：CPU 可跑，GPU 加速

#### 自动字幕（Auto Subtitle）

```
输入视频 → FFmpeg 提取音频(16kHz) → Whisper Base ASR → 带时间戳字幕
                                              ↓
                                       去口癖处理（规则+LLM）
                                              ↓
                                       SRT 字幕文件 → FFmpeg burn in
```

**所需模型**：Whisper Base
**硬件**：CPU 可跑，GPU 加速 3-5x

#### 智能配乐（Smart BGM）

```
输入视频 → EmoBERTa 情绪分类 → 匹配 BGM 库 → 淡入淡出处理 → FFmpeg amix 混音
```

**所需模型**：EmoBERTa（可选，规则匹配也可用）
**硬件**：推荐 GPU

#### 智能配音（Voice Over）

```
LLM 生成脚本 → TTS 语音合成 → FFmpeg 音视频混音
```

**所需模型**：CosyVoice / VITS
**硬件**：CPU 可跑

### 6.5 CPU/GPU 环境功能可行性

#### 6.x.3 GPU 迁移方案

当具备 GPU 资源时，只需修改模型推理设备配置，无需改变代码架构：

**模型加载时的 device 参数调整**：

```python
# 检测 GPU 是否可用
import torch
device = "cuda" if torch.cuda.is_available() else "cpu"

# Whisper
model = whisper.load_model("base", device=device)

# YOLOv8
model = YOLO("yolov8n.pt").to(device)

# EmoBERTa（如使用）
model = model.to(device)
```

**FFmpeg 硬件加速**（可选）：

```bash
# NVIDIA GPU 编码
ffmpeg -i input.mp4 -c:v h264_nvenc output.mp4

# Intel QSV 编码
ffmpeg -i input.mp4 -c:v h264_qsv output.mp4
```

**迁移检查清单**：

```
GPU 方案只需：
□ 安装 NVIDIA GPU 驱动
□ pip install torch --index-url https://download.pytorch.org/whl/cu118
□ 验证：python -c "import torch; print(torch.cuda.is_available())"
□ 模型加载添加 device 参数（自动检测）
□ 可选：FFmpeg 启用硬件编码（h264_nvenc）
```

```python
class FillerWordRemover:
    """去口癖辅助技能"""

    CHINESE_FILLERS = [
        "嗯", "啊", "呃", "哦", "呀", "吧", "呢", "嘛",
        "这个", "那个", "就是说", "然后", "然后呢",
        "所以说", "可以说", "其实", "实际上",
        "对对对", "就是就是", "好吗", "行吗",
        "那什么", "好吧", "说实话", "反正",
    ]

    def remove(self, text: str, use_llm: bool = False) -> str:
        """去除文本中的口癖词"""
        if use_llm:
            return self._remove_with_llm(text)
        return self._remove_with_rules(text)

    def _remove_with_rules(self, text: str) -> str:
        """基于规则的去口癖"""
        for filler in self.CHINESE_FILLERS:
            text = text.replace(filler, "")
        # 清理多余空格
        text = re.sub(r'\s+', ' ', text).strip()
        return text
```

**验收标准**：
- [ ] "我觉得这个，嗯，就是说，产品非常好" → "我觉得这个产品非常好"
- [ ] "对对对，非常棒" → "非常棒"
