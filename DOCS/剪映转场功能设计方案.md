# 剪映转场功能设计方案

## 概述

本文档描述如何在 MediaRefitAgent 中完整集成剪映转场能力。通过直接调用 `pyJianYingDraft` 库，实现：

- 查询所有可用转场类型（200+ 种）
- 在视频片段间应用转场效果
- 自然语言转场推荐
- 统一的 Agent 对话集成

---

## 1. 方案架构

### 1.1 核心模块

```
backend/jianying/
├── __init__.py           # 模块入口
├── client.py             # 剪映客户端（基于 pyJianYingDraft）
├── models.py             # Pydantic 数据模型
├── exceptions.py         # 异常定义
└── transitions.py        # 转场元数据解析

backend/api/fastapi_app.py  # API 端点（修改）
```

### 1.2 工作流程

```
用户请求（添加视频+转场）
    ↓
jianying/client.py 解析转场参数
    ↓
调用 pyJianYingDraft 的 VideoSegment.add_transition()
    ↓
生成草稿 JSON
    ↓
保存草稿到本地
    ↓
返回 draft_url 给用户
    ↓
用户在剪映客户端打开草稿预览
```

## 2. API 接口设计

### 2.1 查询转场列表

**GET** `/api/jianying/transitions`

返回所有可用转场类型。

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `category` | string | 否 | 按分类筛选（如 "基础"、"滑动"） |
| `is_paid` | boolean | 否 | 筛选免费/付费转场 |

**响应示例**：

```json
{
  "success": true,
  "data": {
    "transitions": [
      {
        "id": "叠化",
        "name": "叠化",
        "is_paid": false,
        "default_duration": 0.5,
        "category": "基础",
        "description": "淡入淡出叠加，最常用的转场效果"
      },
      {
        "id": "滑动",
        "name": "滑动",
        "is_paid": false,
        "default_duration": 1.0,
        "category": "滑动",
        "description": "横向滑入滑出"
      }
    ],
    "total": 296,
    "categories": ["基础", "滑动", "擦除", "模糊", "旋转", "分割", "特效"]
  }
}
```

### 2.3 添加视频（支持转场）

**POST** `/api/jianying/add_videos`

**FormData 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `draft_url` | string | 是 | 草稿URL |
| `videos` | string (JSON) | 是 | 视频信息列表 |
| `transition_id` | string | 否 | 转场类型名称 |
| `transition_duration` | int | 否 | 转场时长（微秒） |

**videos JSON 格式**：

```json
[
  {
    "video_url": "https://example.com/video1.mp4",
    "start": 0,
    "end": 5000000,
    "transition": "fade",
    "transition_duration": 500000
  },
  {
    "video_url": "https://example.com/video2.mp4",
    "start": 5000000,
    "end": 10000000
  }
]
```

**transition 字段说明**：

- `transition`：转场类型名称（见转场列表）
- `transition_duration`：转场时长（微秒），默认使用转场默认时长

---

### 2.4 应用转场到已有片段

**POST** `/api/jianying/apply_transition`

为草稿中指定的视频片段应用转场。

**FormData 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `draft_url` | string | 是 | 草稿URL |
| `segment_index` | int | 是 | 片段索引（从 0 开始） |
| `transition_id` | string | 是 | 转场类型名称 |
| `transition_duration` | int | 否 | 转场时长（微秒） |

## 4. 使用示例

### 4.1 创建带转场的草稿

```bash
# 1. 创建草稿
curl -X POST "http://localhost:8004/api/jianying/create_draft" \
  -d "width=1080" -d "height=1920"

# 返回: draft_url = http://localhost:8004/api/jianying/get_draft?draft_id=xxx

# 2. 添加两个视频，使用叠化转场
curl -X POST "http://localhost:8004/api/jianying/add_videos" \
  -d "draft_url=http://localhost:8004/api/jianying/get_draft?draft_id=xxx" \
  -d 'videos=[
    {"video_url":"F:/video/scene1.mp4","start":0,"end":5000000},
    {"video_url":"F:/video/scene2.mp4","start":5000000,"end":10000000}
  ]' \
  -d "transition_id=叠化" \
  -d "transition_duration=500000"

# 3. 保存草稿
curl -X POST "http://localhost:8004/api/jianying/save_draft" \
  -d "draft_url=http://localhost:8004/api/jianying/get_draft?draft_id=xxx"
```

### 4.2 查询并应用转场

```bash
# 1. 查询所有免费转场
curl "http://localhost:8004/api/jianying/transitions?is_paid=false"

# 2. 按分类查询滑动类转场
curl "http://localhost:8004/api/jianying/transitions?category=滑动"

# 3. 为已有片段应用转场
curl -X POST "http://localhost:8004/api/jianying/apply_transition" \
  -d "draft_url=http://localhost:8004/api/jianying/get_draft?draft_id=xxx" \
  -d "segment_index=0" \
  -d "transition_id=百叶窗" \
  -d "transition_duration=500000"
```

### 4.3 Python SDK 示例

```python
from backend.jianying import JianyingClient

client = JianyingClient()

# 创建草稿
draft_url = client.create_draft(width=1080, height=1920)

# 添加视频（带转场）
videos = [
    {"video_url": "F:/video/scene1.mp4", "start": 0, "end": 5000000},
    {"video_url": "F:/video/scene2.mp4", "start": 5000000, "end": 10000000},
]
result = client.add_videos(draft_url, videos, transition_id="叠化")

# 保存草稿
client.save_draft(draft_url)

print(f"草稿已保存，请在剪映中打开: {draft_url}")
```

- 添加转场：在两个视频片段之间添加转场效果
- 更换转场：更换已有的转场为新的类型
- 删除转场：移除视频片段间的转场

## 7. 注意事项

### 7.1 时间单位

所有时间参数单位为**微秒**（1 秒 = 1,000,000 微秒）：
- 0.5 秒 = 500,000 微秒
- 1.0 秒 = 1,000,000 微秒
- 2.5 秒 = 2,500,000 微秒

### 7.2 转场位置

转场效果应用于**前一个片段的末尾**，即：
- 视频 A + 视频 B 添加转场 → 转场效果附加在视频 A 的结束部分
- 片段索引 `segment_index` 指向的是**前一个片段**（视频 A）

### 7.3 付费转场

标记为「付费」的转场需要用户在剪映中开通会员才能使用，否则可能显示为无效效果。

### 7.4 草稿有效期

草稿数据存储在内存中，重启服务后会丢失。请及时调用 `save_draft` 接口保存草稿。
