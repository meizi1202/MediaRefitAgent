# 前端多轮对话流程

## 流程图

```
┌─────────────────────────────────────────────────────────────┐
│                      用户发送消息                              │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  有 currentSessionId 且 无新文件上传?                          │
└─────────────────────────────────────────────────────────────┘
                    Yes                    No
                     │                      │
                     ▼                      ▼
┌─────────────────────────┐    ┌─────────────────────────────┐
│  POST /api/agent/      │    │  POST /api/agent/chat       │
│       continue         │    │  (新会话或带文件)             │
│  (session_id + message)│    │  (session_id + message + file)│
└─────────────────────────┘    └─────────────────────────────┘
                     │                      │
                     └──────────┬───────────┘
                                ▼
┌─────────────────────────────────────────────────────────────┐
│                     获取 AI 响应                              │
│                     data.message                              │
└─────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│                   更新 currentSessionId                        │
│                   保存消息到 sessions[]                        │
│                   渲染对话列表                                │
└─────────────────────────────────────────────────────────────┘
```

## 判断逻辑

```javascript
// 判断是否继续已有会话（没有上传新文件且有 session_id）
const hasFile = formData.get('file');  // 有新文件?
const isContinue = currentSessionId && !hasFile;  // 继续会话?

if (isContinue) {
    // 继续: /api/agent/continue (无文件)
} else {
    // 新会话: /api/agent/chat (可能带文件)
}
```

## API 接口

| 接口 | 用途 | 参数 |
|------|------|------|
| `POST /api/agent/chat` | 创建新会话或继续已有会话 | `message`, `session_id`(可选), `file`(可选) |
| `POST /api/agent/continue` | 继续已有会话 | `message`, `session_id` |
| `GET /api/agent/sessions` | 获取所有会话列表 | - |
| `GET /api/agent/session/{id}` | 获取单个会话状态 | - |
| `DELETE /api/agent/session/{id}` | 删除会话 | - |

## 关键变量

| 变量 | 说明 |
|------|------|
| `currentSessionId` | 当前会话 ID |
| `sessions[]` | 前端会话列表（本地存储） |
| `selectedFile` | 当前选中的视频文件 |
| `selectedFiles[]` | 多文件列表（用于拼接） |

## 视频持久化

后端将视频文件持久化到会话目录：

```
~/.mediarefit/sessions/{session_id}/
├── video.mp4           # 主视频
└── video_0.mp4, video_1.mp4  # 拼接用的多个视频
```

这样在后续轮次中，即使临时文件被删除，也能从持久化目录读取视频文件。
