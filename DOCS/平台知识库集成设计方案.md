# 设计方案：公众号平台知识库集成

## Context

用户希望将"公众号名称 → 视频比例 + 缺省时长要求"的知识存入智能体，使 Agent 在用户提及相应平台时能自动提取信息辅助决策。

| 公众号名称 | 视频比例 | 缺省时长要求 |
|-----------|---------|-------------|
| 抖音 / 抖音极速 | 9:16 | 15‑60s |
| 快手 | 9:16 | 30‑90s |
| 视频号 / 央视频视频号 | 9:16 + 1:1 | 60s优先 |
| B站 / 央视频B站 | 16:9 | 2‑6 min |
| 小红书 | 3:4 | 15‑30s |
| 微博视频 / 头条号 | 16:9 | 30‑90s |
| 央视自有端(央视频 / CCTV) | 16:9 | 全长版本 |

现有 `backend/video/platforms.py` 已有 `PLATFORM_SETTINGS`，但缺少"缺省时长要求"字段，且知识未与 Agent 的意图理解和对话流程集成。

---

## 推荐方案

### 核心思路

在 `backend/agent/` 下新建 `knowledge/platform_guide.py`，将平台信息结构化存储，并通过以下方式与 Agent 集成：

1. **在 `analyze_intent` 中添加平台识别** - 当用户提到公众号名称时，自动识别目标平台
2. **在对话提示中注入平台信息** - 在用户确认参数时，提供符合目标平台要求的建议（如"抖音建议15-60秒"）
3. **扩展 `prompts.py`** - 添加平台知识查询的 Prompt 片段

---

## 详细设计

### 1. 新建知识模块

**文件**: `backend/agent/knowledge/platform_guide.py`（需新建 `knowledge/` 目录）

```python
from typing import Optional

# 公众号平台知识库（不含已在 platforms.py 中定义的技术参数）
PLATFORM_GUIDE = {
    "抖音": {
        "ratio": "9:16",
        "duration": "15-60秒",
        "alias": ["抖音极速", "douyin"],
    },
    "快手": {
        "ratio": "9:16",
        "duration": "30-90秒",
        "alias": ["kuaishou"],
    },
    "视频号": {
        "ratio": "9:16 或 1:1",
        "duration": "60秒优先",
        "alias": ["央视频视频号", "weixinshipin"],
    },
    "B站": {
        "ratio": "16:9",
        "duration": "2-6分钟",
        "alias": ["bilibili", "央视频B站"],
    },
    "小红书": {
        "ratio": "3:4",
        "duration": "15-30秒",
        "alias": ["xiaohongshu"],
    },
    "微博视频": {
        "ratio": "16:9",
        "duration": "30-90秒",
        "alias": ["头条号"],
    },
    "央视频": {
        "ratio": "16:9",
        "duration": "全长版本",
        "alias": ["CCTV"],
    },
    "央视自有端": {
        "ratio": "16:9",
        "duration": "全长版本",
    },
}


def match_platform(user_input: str) -> Optional[str]:
    """从用户输入中匹配平台名称，返回标准平台名（含别名匹配）"""
    for platform, info in PLATFORM_GUIDE.items():
        if platform in user_input:
            return platform
        for alias in info.get("alias", []):
            if alias in user_input:
                return platform
    return None


def get_platform_guide(platform: str) -> Optional[dict]:
    """查询平台指南信息"""
    return PLATFORM_GUIDE.get(platform)


def format_platform_suggestion(platform: str) -> str:
    """生成符合平台要求的建议文本，用于对话提示"""
    info = get_platform_guide(platform)
    if not info:
        return ""
    return f"{platform}推荐{info['ratio']}，时长{info['duration']}效果最佳"
```

### 2. 集成到意图分析

**文件**: `backend/agent/nodes/analyze.py`

在 `IntentParser` 类中添加平台识别逻辑：

```python
# 新增 import
from backend.agent.knowledge.platform_guide import match_platform, format_platform_suggestion

# 在 IntentParser.parse() 返回结果中新增 platform 字段
def parse(self, user_input: str) -> dict:
    # ... 现有解析逻辑 ...

    # 识别平台
    platform = match_platform(user_input)
    if platform:
        result["platform"] = platform
        result["platform_explicit"] = True
        # 注入平台建议到 pending_question
        if not result.get("target_orientation"):
            suggestion = format_platform_suggestion(platform)
            result["pending_question"] = f"好的，{suggestion}。请问目标方向是竖屏还是横屏？"

    return result
```

### 3. 扩展 Prompt 模板

**文件**: `backend/agent/prompts.py`

```python
def get_platform_suggestion_prompt(platform: str) -> str:
    """生成符合平台要求的建议文本"""
    info = PLATFORM_GUIDE.get(platform, {})
    if not info:
        return ""
    return f"（提示：{platform}推荐{info['ratio']}，时长{info['duration']}）"
```
