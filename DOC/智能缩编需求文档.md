# 智能缩编技能 - 需求文档

## 1. 概述

### 1.1 背景

视频内容创作中，经常需要将长视频或不符合目标平台要求的视频进行"缩编"处理。智能缩编技能通过 AI 技术实现自动化压缩、精简和裁剪，降低创作门槛，提升效率。

### 1.2 目标

在 MediaRefitAgent 视频编辑智能体中添加"智能缩编"技能，支持三种核心场景：智能压缩、内容缩编、智能裁剪。

### 1.3 功能范围

本技能涵盖以下缩编类别：

| 类别 | 功能 |
|------|------|
| 智能压缩 | H.265/AV1 重编码、无声段删除、慢动作去除 |
| 内容缩编 | 精彩片段提取、视频摘要、冗余内容删除 |
| 智能裁剪 | 主体检测、动态跟踪、构图优化 |

## 2. 功能详细说明

### 2.1 智能压缩（Smart Compression）

#### 2.1.1 功能描述

在不明显损失画质的前提下，减小视频文件体积或缩短时长。

#### 2.1.2 技术方案

| 维度 | 方案 | 技术实现 | 参数 |
|------|------|----------|------|
| **H.265 重编码** | FFmpeg H.265/HEVC | `ffmpeg -i input.mp4 -c:v libx265 -crf 23 output.mp4` | CRF 18-28 |
| **AV1 重编码** | FFmpeg AV1 (SVT-AV1) | `ffmpeg -i input.mp4 -c:v libsvtav1 -crf 30 output.mp4` | 更小体积但更慢 |
| **智能码率控制** | ABR/CBR/VBR | 基于内容复杂度动态调整 | `-b:v 2M -maxrate 4M` |
| **关键帧间隔** | 场景感知 GOP | `gop=scene-aware` | 减少冗余 I 帧 |
| **无声段删除** | 音频能量检测 | VAD + FFmpeg segment | 低于阈值 -60dB |
| **慢动作去除** | 帧率检测 + 抽帧 | 120fps→60fps 智能抽帧 | `minterpolate` |

#### 2.1.2.1 当前实现状态

> ✅ **已实现** - 2026-08-17

**实现方式**：H.265 重编码（CRF=23）

```python
# video/condenser.py - _smart_compress()
subprocess.run([
    "ffmpeg", "-i", video_path,
    "-c:v", "libx265", "-crf", "23",
    "-c:a", "aac", "-b:a", "128k",
    output_path, "-y"
])
```

**特点**：
- 仅做 H.265 重编码压缩，不删除片段
- 时长保持不变，只减小文件体积
- 压缩比约 40-60%（取决于内容复杂度）

**与内容缩编的区别**：
| 对比项 | 智能压缩 | 内容缩编 |
|--------|----------|----------|
| 目的 | 减小文件体积 | 缩短视频时长 |
| 方式 | 重编码压缩 | 提取精彩片段 |
| 时长变化 | 不变 | 缩短 |
| 片段删除 | 否 | 是 |

#### 2.1.3 处理流程

```
输入视频 → 场景分析 → 编码方案选择 → 智能压缩处理 → 输出
              ↓
         无声段/慢动作检测 → 删除冗余片段
```

#### 2.1.4 参数配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `codec` | str | "h265" | 编码器：h264/h265/av1 |
| `quality` | str | "medium" | 质量：low/medium/high/lossless |
| `remove_silent` | bool | true | 删除无声片段 |
| `remove_slowmo` | bool | false | 删除慢动作冗余 |
| `target_duration` | int | null | 目标时长（秒），null=保持原长 |
| `crf` | int | 23 | 质量参数（越小质量越高）|

#### 2.1.5 使用场景

- "压缩这个视频，但要保持清晰度"
- "把10分钟视频压缩到3分钟"
- "删除会议视频中的沉默片段"

### 2.2 内容缩编（Content Condensation）

#### 2.2.1 功能描述

从长视频中提取精华，生成浓缩版本。通过分析音频能量、语音内容等，自动选出最精彩的片段进行拼接。

#### 2.2.2 技术方案

| 功能 | 技术实现 | 工具/模型 |
|------|----------|-----------|
| **精彩片段识别** | 多维度评分算法 | 画面复杂度 + 音频能量 + 动作强度 + 人脸检测 |
| **场景分割** | 镜头边界检测 + 内容相似度 | FFmpeg scene detection + 深度学习 |
| **视频摘要-文字** | Whisper ASR + LLM 摘要 | Whisper + Qwen/Baichuan |
| **视频摘要-视频** | 关键帧拼接 + 语音摘要 | FFmpeg concat + TTS |
| **冗余片段删除** | 相似度检测 + 重复消除 | 帧差分 + SSIM |

#### 2.2.2.1 当前实现状态

> ✅ **已实现** - 2026-08-17

**实现方式**：Whisper ASR + 音频能量评分选段 + FFmpeg 拼接

```
处理流程：
1. FFmpeg 提取音频 (16kHz WAV)
2. Whisper Base 语音识别 → 获取带时间戳的文本片段
3. 基于音频能量对片段评分（能量高的片段更可能是精彩内容）
4. 按评分排序，选取总时长不超过目标时长的片段
5. FFmpeg filter_complex 拼接各片段
6. 生成对应 SRT 字幕
```

**代码位置**：`video/condenser.py` - `_condense_with_funclip()`

**特点**：
- 自动识别语音内容，保留有对话/旁白的精彩片段
- 基于音频能量评分，优先保留声音较大的片段
- 输出带字幕，支持烧录
- 时长可精确控制（目标时长参数）

**与智能压缩的区别**：
| 对比项 | 内容缩编 | 智能压缩 |
|--------|----------|----------|
| 目的 | 缩短视频时长 | 减小文件体积 |
| 方式 | 提取精彩片段拼接 | 重编码压缩 |
| 时长变化 | 缩短（可指定目标时长） | 不变 |
| 内容变化 | 删除部分片段 | 保留全部内容 |

#### 2.2.3 处理流程

```
输入视频 → 精彩片段评分 → 场景分割 → 语义理解 → 精选片段 → 拼接输出
              ↓                    ↓
         去除重复/冗余        生成文字/视频摘要
```

#### 2.2.4 精彩片段评分算法

```python
# 多维度评分
final_score = (
    audio_energy_score * 0.4 +      # 音量峰值、音乐节奏
    visual_complexity_score * 0.3 + # 边缘密度、纹理复杂度
    motion_intensity_score * 0.3    # 帧间差异、运动向量
)
# 可选加分项
+ face_detected * 0.1               # 检测到人脸
+ text_changes * 0.05               # 字幕/文字变化
+ audio_peak * 0.1                  # 音频峰值（如欢呼声）
```

#### 2.2.5 参数配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `target_duration` | int | 60 | 目标时长（秒） |
| `num_clips` | int | 5 | 片段数量 |
| `min_clip_duration` | int | 3 | 最小片段时长（秒） |
| `score_weights` | dict | {audio:0.4, visual:0.3, motion:0.3} | 评分权重 |
| `remove_duplicates` | bool | true | 是否去除重复片段 |
| `summary_type` | str | "video" | 摘要类型：video/text/mixed |

#### 2.2.6 使用场景

- "提取这场演唱会的精彩片段"
- "生成会议的文字摘要"
- "把2小时电影缩到5分钟精华版"

### 2.3 智能裁剪（Smart Cropping）

#### 2.3.1 功能描述

自动裁剪出符合目标画幅/平台的关键画面区域。通过 YOLO 检测视频中的主体（人脸/物体），计算出包含最多主体的裁剪区域。

#### 2.3.2 技术方案

| 功能 | 技术实现 | 工具/模型 |
|------|----------|-----------|
| **主体检测** | YOLO 目标检测 | YOLOv8 + 人脸/物体检测 |
| **焦点选择** | 显著性检测 + 人脸优先 | Saliency Detection + Face Detection |
| **动态跟踪** | 基于光流的跟踪 | FARFlow / ByteTrack |
| **构图优化** | 黄金比例 + 三分法 | 规则引擎 |
| **平滑过渡** | 锚点插值 | ease-in/out 曲线 |

#### 2.3.2.1 当前实现状态

> ✅ **已实现** - 2026-08-17

**实现方式**：YOLOv8 采样检测 + FFmpeg 静态裁剪

```
处理流程：
1. 均匀采样视频中的 N 帧（默认 10 帧）
2. YOLOv8 对每帧进行目标检测
3. 合并所有检测框，计算主体区域的中心点
4. 根据目标比例计算裁剪窗口位置（尽量包含最多主体）
5. FFmpeg crop filter 应用裁剪
```

**代码位置**：
- `video/condenser.py` - `_smart_crop()`
- `ml/smart_cropper.py` - `SmartCropper.crop_video_frames()`

**特点**：
- 基于 YOLO 检测结果选择最佳裁剪区域
- 适用于横屏转竖屏（16:9 → 9:16）等场景
- 裁剪区域固定（不跟踪主体运动）
- 保持原视频时长不变，仅改变画面构图

**与横竖屏转换的区别**：
| 对比项 | 智能裁剪 | 横竖屏转换（pad模式） |
|--------|----------|----------------------|
| 目的 | 裁剪主体区域 | 保持全部内容 |
| 画面损失 | 可能丢失边缘内容 | 无损失，但有黑边 |
| 主体 | 以检测到的主体为中心 | 原始画面居中 |

#### 2.3.4 焦点模式说明

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| `face` | 优先锁定人脸 | 人物发言、采访、vlog |
| `object` | 锁定检测到的物体 | 产品展示、运动物体 |
| `center` | 固定中心裁剪 | 固定镜头、稳定画面 |
| `auto` | 自动选择（人脸>物体>中心） | 通用场景 |

#### 2.3.5 平滑算法

```python
# 焦点轨迹平滑
smoothed_center = original_center * smooth_factor + previous_center * (1 - smooth_factor)

# 边界约束（确保裁剪窗口在画面内）
crop_x = max(0, min(crop_x, frame_width - crop_width))
crop_y = max(0, min(crop_y, frame_height - crop_height))
```

#### 2.3.6 参数配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `target_ratio` | str | "9:16" | 目标画幅：9:16/16:9/1:1/4:3 |
| `focus_mode` | str | "auto" | 焦点模式：face/object/center/auto |
| `motion_track` | bool | true | 是否跟踪运动主体 |
| `smooth_factor` | float | 0.3 | 平滑系数（0-1） |
| `padding` | int | 10 | 安全边距（%） |
| `crop_strategy` | str | "smart" | 裁剪策略：smart/center/ignore_motion |

#### 2.3.7 使用场景

- "把横屏转成9:16竖屏"
- "提取视频中的人物主体"
- "裁剪出适合抖音的竖屏版本"

## 8. 与现有技能协同

### 8.1 与智能剪辑技能的对比

| 维度 | 智能缩编 | 智能剪辑 |
|------|----------|----------|
| **核心理念** | **压缩精简** — 减小文件体积或时长，保留核心内容 | **创作包装** — 生成可直接发布的精美短视频 |
| **关注点** | 内容完整性 vs 时长/体积 | 观赏性、传播性、平台适配 |
| **输出** | 精简版视频（更短/更小/新画幅） | 带字幕/BGM/转场的可发布成品 |
| **典型场景** | "把视频压缩到3分钟" | "帮我剪辑一个抖音视频" |
| **AI 依赖** | Whisper + YOLO（较轻量） | Whisper + EmoBERTa + TTS + 多种模型 |

**互补关系**：
- 智能缩编 → 智能剪辑（先压缩后精剪）
- 智能剪辑 → 智能缩编（先裁剪后提取）

### 8.2 与老视频修复技能协同

| 场景 | 工作流 |
|------|--------|
| 老视频缩编发布 | 老视频修复 → 智能缩编 → 输出成品 |
| 修复后生成短内容 | 修复（去噪/补帧）→ 精彩片段提取 → 短视频 |

### 8.3 与智能剪辑技能协同

| 场景 | 工作流 |
|------|--------|
| 先压缩后剪辑 | 智能压缩 → 智能剪辑（字幕/BGM） |
| 先裁剪后精剪 | 智能裁剪 → 精彩片段提取 → 输出 |

### 8.4 技能共享模块

| 模块 | 共享方 | 用途 |
|------|--------|------|
| `smart_cropper.py` | 老视频修复 + 智能剪辑 + 智能缩编 | 智能裁剪 |
| `processor.py` | 所有技能 | 基础视频处理 |
| `video_agent.py` | 所有技能 | 意图识别和对话 |
