## 一、产品概述

MediaRefitAgent 是一个**一站式视频智能编辑平台**，基于专业多媒体编解码底座、大模型工作流编排引擎、高性能异步微服务架构构建。具备自然语言语义解析驱动任务、多轮对话式业务调参、处理进度流式实时回传等核心能力。

**核心功能**：横竖屏转换 / 智能裁剪 / 精彩片段提取 / 老视频修复 / 智能配乐 / 自动字幕 / 视频摘要 / 滤镜转场 / TTS配音 / 平台适配检查

**核心价值**：让视频处理从"需要学习专业软件"变成"说一句话就能搞定"。

### 技术栈

| 技术 | 用途 | 说明 |
|------|------|------|
| **FFmpeg** | 视频处理核心 | 横竖屏转换、压缩、裁剪、拼接、字幕、转场 |
| **LangGraph** | Agent 状态机 | 多轮对话流程控制、意图路由 |
| **FastAPI** | API 服务 | 40+ RESTful 端点 |
| **MinMax LLM** | 意图解析 | 自然语言理解、参数提取 |
| **YOLOv8n** | 智能裁剪 | 主体检测、主体跟随裁剪 |
| **Whisper** | 语音识别 | 字幕生成、去口癖、精彩片段提取 |
| **Edge-TTS** | 文字转语音 | AI 配音 |

## 三、功能列表

### 3.1 按智能化程度分类

#### 传统功能（无需AI）

| 功能 | 说明 | 使用技术 |
|------|------|----------|
| rotate | 旋转90°/180°/270° | FFmpeg |
| pad | 填充黑边，保持内容完整 | FFmpeg |
| crop | 中心裁剪 | FFmpeg |
| stretch | 拉伸到目标比例 | FFmpeg |
| compress | 视频压缩(H.264/H.265) | FFmpeg |
| trim | 按时间裁剪 | FFmpeg |
| concat | 视频拼接 | FFmpeg |
| 字幕烧录 | SRT字幕嵌入视频 | FFmpeg |
| 转场效果 | 片间转场动画 | FFmpeg 滤镜链 |
| 片头片尾 | 模板化包装 | FFmpeg |
| 平台检查 | 规则校验 | 规则引擎 |

#### AI 增强功能

| 功能 | 说明 | 使用技术 | GPU需求 |
|------|------|----------|---------|
| **smart_crop** | YOLO智能裁剪，保留主体 | YOLOv8n | **需要** |
| 智能配乐 | 情绪识别+自动BGM匹配 | MinMax | 否 |
| TTS配音 | AI文字转语音 | Edge-TTS / MinMax | 否 |
| 封面生成 | 智能提取精彩帧 | YOLO | **需要** |

#### 深度 AI 功能

| 功能 | 说明 | 使用技术 | GPU需求 |
|------|------|----------|---------|
| 精彩片段提取 | 自动识别高光时刻 | Whisper + 能量分析 | 可选 |
| 去口癖 | 自动删除语气词停顿 | FunClip + MinMax | 可选 |
| 自动字幕 | 语音识别+标点还原 | Whisper | 否 |
| 老视频修复 | 去噪/补帧/超分/色彩校正 | FFmpeg + AAVS | **需要** |
| 内容分析 | 场景/人物/情绪标签 | MiniMax-M3 | 可选 |
| 智能缩编 | 长视频自动精简 | FunClip + MinMax | 可选 |
| 视频摘要 | 生成文字摘要 | Whisper + LLM | 否 |

### 3.3 GPU 资源需求

| 功能 | 当前实现 | GPU优化效果 |
|------|----------|------------|
| 智能裁剪 (YOLO) | CPU ~200ms/帧 | GPU ~10ms/帧 **提升20倍** |
| 封面生成 | CPU筛选 | GPU YOLO+CLIP 快速筛选 |
| 老视频-补帧 | CPU插帧 慢 | GPU光流法 **快10倍** |
| 老视频-超分 | CPU 耗时很长 | GPU 实时超分 |
| 内容分析 | 逐帧分析 慢 | GPU批量处理 **快5-10倍** |
| 精彩片段提取 | FunClip CPU分析 | GPU加速音频分析 |
