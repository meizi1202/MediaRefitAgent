# 智能剪辑技能 - 需求文档

## 1. 概述

### 1.1 背景
视频内容创作者面临大量素材需要快速剪辑成品的痛点。传统剪辑需要专业技能和大量时间，智能剪辑技能通过 AI 技术实现自动化剪辑，降低创作门槛，提升效率。

### 1.2 目标
在 MediaRefitAgent 视频编辑智能体中添加"智能剪辑"技能，支持从长视频素材自动识别精彩片段、智能裁剪转场、自动字幕配音，一键生成可发布的短视频。

### 1.3 功能范围
本技能涵盖以下剪辑类别：
| 类别 | 功能 |
|------|------|
| 智能分析 | 精彩片段识别、高光时刻检测、场景分割 |
| 智能剪辑 | 自动剪辑精彩片段、AI生成短视频 |
| 智能增强 | 智能裁剪、智能转场 |
| 内容生成 | 自动字幕、智能配音/配乐 |
| 视频摘要 | 精彩集锦生成、视频摘要 |

## 2. 功能详细说明

### 2.1 智能分析

#### 2.1.1 精彩片段识别（Highlight Detection）
- **功能描述**：从长视频中自动识别并提取最精彩、最有价值的片段
- **技术方案**：多维度评分算法
  - 画面复杂度（边缘密度、纹理）
  - 音频能量（音量峰值、音乐节奏）
  - 动作强度（帧间差异、运动向量）
  - 人脸数量与表情（正脸、微笑、动作）
  - 文本/字幕变化（信息密度）
- **评分权重**：可配置（默认：音频40%、画面30%、动作30%）
- **使用场景**："从会议录像提取精彩片段"、"从直播提取高光时刻"

#### 2.1.2 场景分割（Scene Segmentation）
- **功能描述**：自动将视频分割成多个语义场景
- **技术方案**：镜头边界检测 + 内容相似度分析
- **参数选项**：
  - 分割模式：硬切 / 渐变 / 混合
  - 最小场景时长：1-30秒
  - 分割粒度：粗略 / 中等 / 精细
- **使用场景**："将视频按场景自动分段"、"提取每个场景的封面"

#### 2.1.3 内容理解（Content Understanding）
- **功能描述**：理解视频内容，提取关键信息
- **技术方案**：多模态 AI 模型
- **提取信息**：
  - 场景类型（室内/室外/人物/风景）
  - 说话内容（语音识别）
  - 文字信息（OCR）
  - 物体标签（目标检测）
- **使用场景**："提取视频关键信息"、"自动生成视频描述"

### 2.2 智能剪辑

#### 2.2.1 自动精彩片段剪辑（Auto Highlight Clip）
- **功能描述**：从长视频中自动剪辑出最精彩的片段，生成精华集锦
- **技术方案**：精彩片段识别 → 评分排序 → 精选 → 拼接
- **参数选项**：
  - 目标时长：15秒 / 30秒 / 60秒 / 1分钟 / 自定义
  - 片段数量：3-10个
  - 最小片段时长：3-15秒
  - 片段间隔：0-2秒（留白）
  - 是否去重：开启/关闭
- **输出格式**：单片段 / 拼接合集
- **使用场景**："生成一分钟精彩集锦"、"提取Top10高光时刻"

#### 2.2.2 AI生成短视频（Auto Short Video）
- **功能描述**：从素材自动生成适合社交媒体发布的短视频
- **技术方案**：内容分析 → 脚本生成 → 智能剪辑 → 配乐字幕
- **参数选项**：
  | 参数 | 类型 | 默认值 | 说明 |
  |------|------|--------|------|
  | `platform` | str | "auto" | 平台：douyin/kuaishou/bilibili/youtube/auto |
  | `duration` | int | 60 | 目标时长（秒） |
  | `aspect_ratio` | str | "9:16" | 画幅：9:16/16:9/1:1/4:3 |
  | `style` | str | "viral" | 风格：viral/情感/资讯/教程/auto |
  | `music` | bool | true | 是否配乐 |
  | `subtitle` | bool | true | 是否字幕 |
- **使用场景**："生成抖音风格短视频"、"一键生成小红书视频"

#### 2.2.3 视频摘要（Video Summary）
- **功能描述**：生成视频的浓缩摘要版本
- **技术方案**：抽取关键帧 + 语音摘要 + 字幕
- **参数选项**：
  - 摘要长度：30秒 / 1分钟 / 3分钟
  - 摘要类型：图文 / 视频片段 / 混合
- **使用场景**："生成视频速读版本"、"提取视频核心内容"

### 2.3 智能增强

#### 2.3.1 智能裁剪（Smart Crop）
- **功能描述**：自动选择最佳构图区域进行裁剪
- **技术方案**：Saliency Detection + Face Detection + 黄金比例
- **参数选项**：
  | 参数 | 类型 | 默认值 | 说明 |
  |------|------|--------|------|
  | `target_ratio` | str | "9:16" | 目标画幅 |
  | `focus_mode` | str | "auto" | 焦点模式：face/object/center/auto |
  | `motion_track` | bool | true | 是否跟踪运动主体 |
  | `padding` | int | 10 | 安全边距（%） |
- **已复用**：可复用现有 `ml/smart_cropper.py` 中的 YOLO 裁剪能力
- **使用场景**："把横屏转竖屏"、"提取视频重点区域"

#### 2.3.2 智能转场（Smart Transition）
- **功能描述**：在片段切换处自动添加合适的转场效果
- **技术方案**：场景类型匹配 + AI 推荐
- **转场类型**：
  | 转场 | 适用场景 |
  |------|----------|
  | 淡入淡出 | 情绪过渡、场景转换 |
  | 滑动 | 平行叙事、对比 |
  | 缩放 | 强调主体、节奏变化 |
  | 模糊 | 焦点转换 |
  | 旋转 | 场景切换 |
  | 溶解 | 柔和过渡 |
- **参数选项**：
  - 转场时长：0.3-2秒
  - 转场类型：自动推荐 / 指定类型 / 随机
  - 转场强度：轻度 / 中度 / 强力
- **使用场景**："让视频片段衔接更流畅"、"添加电影感转场"

---

### 2.4 内容生成

#### 2.4.1 自动字幕（Auto Subtitle）
- **功能描述**：自动识别语音并生成同步字幕
- **技术方案**：Whisper / FunASR 语音识别
- **参数选项**：
  | 参数 | 类型 | 默认值 | 说明 |
  |------|------|--------|------|
  | `language` | str | "auto" | 语种：auto/zh/en/ja/... |
  | `style` | str | "default" | 样式：default/minimal/emoji/... |
  | `position` | str | "bottom" | 位置：bottom/top/center |
  | `font_size` | int | 24 | 字号 |
  | `bg` | bool | true | 是否背景框 |
  | `keyword_highlight` | bool | false | 关键词高亮 |
- **使用场景**："自动生成字幕"、"添加高亮字幕"

#### 2.4.2 智能配音（Voice Over）
- **功能描述**：为视频添加 AI 配音
- **技术方案**：TTS（Text-to-Speech）语音合成
- **参数选项**：
  | 参数 | 类型 | 默认值 | 说明 |
  |------|------|--------|------|
  | `voice` | str | "female_young" | 音色：female_young/male_young/female_warm/... |
  | `rate` | float | 1.0 | 语速（0.5-2.0） |
  | `pitch` | float | 1.0 | 音调（0.5-2.0） |
  | `volume` | float | 1.0 | 音量（0-1.5） |
  | `emotion` | str | "neutral" | 情感：neutral/happy/sad/excited |
- **使用场景**："添加旁白解说"、"多语言配音"

#### 2.4.3 智能配乐（Smart BGM）
- **功能描述**：自动为视频匹配合适的背景音乐
- **技术方案**：内容分析 → 情绪识别 → 音乐匹配
- **参数选项**：
  | 参数 | 类型 | 默认值 | 说明 |
  |------|------|--------|------|
  | `music_library` | str | "built-in" | 音乐库：built-in/custom/platform |
  | `mood` | str | "auto" | 情绪：auto/ upbeat/calm/dramatic/... |
  | `tempo` | str | "auto" | 节奏：auto/fast/slow/medium |
  | `volume` | float | 0.3 | BGM音量（0-1.0） |
  | `fade` | bool | true | 淡入淡出 |
  | `beat_sync` | bool | true | 节拍同步 |
- **使用场景**："自动添加背景音乐"、"匹配视频情绪的BGM"

### 3.3 AI 模型选型

| 功能 | 推荐模型 | 模型大小 | 推理速度 | 精度 |
|------|---------|----------|---------|------|
| 精彩片段识别 | 自建多维度评分 | - | 快 | 中 |
| 人脸检测 | YOLOv8-Face | ~20MB | 快 | 高 |
| 语音识别 | Whisper Base | ~140MB | 中 | 高 |
| 情感分类 | EmoBERTa | ~400MB | 中 | 高 |
| 字幕生成 | Whisper + NLLB | ~300MB | 慢 | 高 |
| 语音合成 | CosyVoice / VITS | ~200MB | 中 | 高 |
| 物体检测 | YOLOv8 | ~50MB | 快 | 高 |

### 3.4 FFmpeg 剪辑命令方案

| 操作 | 命令片段 | 说明 |
|------|---------|------|
| 片段提取 | `ffmpeg -ss {start} -i input.mp4 -t {duration} -c copy` | 快速无损提取 |
| 片段拼接 | `ffmpeg -f concat -i list.txt -c copy` | 拼接无重新编码 |
| 转场-淡入淡出 | `xfade=transition=fade:duration=1:offset={offset}` | 淡入淡出 |
| 转场-滑动 | `xfade=transition=slideright:duration=0.5` | 滑动转场 |
| 智能裁剪 | `crop=iw:ih*0.8` + 缩放 | 保持焦点区域 |
| 字幕叠加 | `drawtext=text='{text}':fontsize=24` | 字幕烧录 |
| 音频混音 | `amix=inputs=2:duration=longest:dropout_transition=2` | BGM混音 |

## 8. 与现有技能协同

### 8.1 与智能缩编技能的对比

| 维度 | 智能剪辑 | 智能缩编 |
|------|----------|----------|
| **核心理念** | **创作包装** — 生成可直接发布的精美短视频 | **压缩精简** — 减小文件体积或时长，保留核心内容 |
| **关注点** | 观赏性、传播性、平台适配 | 内容完整性 vs 时长/体积 |
| **输出** | 带字幕/BGM/转场的可发布成品 | 精简版视频（更短/更小/新画幅） |
| **典型场景** | "帮我剪辑一个抖音视频" | "把视频压缩到3分钟" |
| **AI 依赖** | Whisper + EmoBERTa + TTS + 多种模型 | Whisper + YOLO（较轻量） |

**互补关系**：
- 智能缩编 → 智能剪辑（先压缩后精剪）
- 智能剪辑 → 智能缩编（先裁剪后提取）

### 8.2 与老视频修复技能协同

| 场景 | 工作流 |
|------|--------|
| 老视频智能剪辑 | 老视频修复 → 智能剪辑 → 输出成品 |
| 修复后生成短视频 | 修复（去噪/补帧）→ 智能裁剪/字幕 → 短视频 |

### 8.3 技能共享模块

| 模块 | 共享方 | 用途 |
|------|--------|------|
| `smart_cropper.py` | 老视频修复 + 智能剪辑 | 智能裁剪 |
| `processor.py` | 所有技能 | 基础视频处理 |
| `video_agent.py` | 所有技能 | 意图识别和对话 |
