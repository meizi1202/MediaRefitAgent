# 新增功能开发指南

本文档说明如何在 MediaRefitAgent 中添加一个新的视频处理功能。

## 快速参考

增加新功能时，只需修改以下 5 个位置：

| 文件 | 修改内容 |
|------|----------|
| `backend/agent/nodes/analyze.py` | `FEATURE_TO_STEP` 映射 + UI 参数解析 + 响应消息 |
| `backend/agent/nodes/routing.py` | `FEATURE_TO_STEP` 映射 |
| `backend/agent/nodes/execute.py` | 执行函数 |
| `frontend/src/stores/app.ts` | `formatSelectedParams()` 添加参数格式化 |
| `frontend/src/types.ts` | 添加 Feature 类型（如果需要） |

## 详细步骤

### 1. 后端 - 分析节点 (`analyze.py`)

**1.1 添加步骤映射**

```python
FEATURE_TO_STEP = {
    "compress": "execute_compress",
    "trim": "execute_trim",
    "concat": "execute_concat",
    "condense": "execute_condense",
    "restore": "execute_restore",
    "editor": "execute_editor",
    "info": "execute_info",
    "your_feature": "execute_your_feature",  # 新增
}
```

**1.2 添加 UI 参数解析**

在 `_parse_ui_params` 函数中添加参数解析逻辑（如果需要从 UI 面板获取参数）。

**1.3 添加意图分支**

在 `analyze_intent` 函数的 UI 参数解析块中添加：

```python
elif feature == "your_feature":
    # 验证参数完整性
    all_params_provided = True  # 或根据实际参数判断
    if all_params_provided:
        llm_response = "好的，我来处理..."
```

### 2. 后端 - 路由节点 (`routing.py`)

**2.1 添加步骤映射**

与 `analyze.py` 保持一致的 `FEATURE_TO_STEP` 映射。

### 3. 后端 - 执行节点 (`execute.py`)

**3.1 添加执行函数**

```python
def execute_your_feature(state: VideoAgentState) -> VideoAgentState:
    """执行你的功能"""
    video_path = state.get("temp_video_path") or state.get("video_path")

    if not video_path:
        state["error"] = "视频文件不存在"
        state["current_step"] = "confirm_complete"
        return state

    try:
        # 你的处理逻辑
        output_path = "..."

        state["current_step"] = "confirm_complete"
        _append_message(state, "assistant", f"处理完成！\n[PREVIEW:{output_path}]")
    except Exception as e:
        state["error"] = str(e)
        state["current_step"] = "confirm_complete"
        _append_message(state, "assistant", f"处理异常: {str(e)}")

    return state
```

### 4. 前端 - 状态管理 (`app.ts`)

**4.1 添加参数格式化**

在 `formatSelectedParams()` 函数中添加：

```typescript
// 你的功能参数
if (currentFeature.value === 'your_feature' && yourParam.value) {
  parts.push(`你的参数=${yourParam.value}`);
}
```

### 5. 前端 - 类型定义 (`types.ts`)

如需要，在 `Feature` 类型中添加新功能标识。

### 6. 前端 - 面板组件 (`panels/`)

如需要，在 `panels/` 目录下创建对应的面板组件。

## 注意事项

### pending_question 必须清除

当参数完整时，必须清除 `pending_question` 避免重复提问：

```python
# 正确方式：使用 _complete_params_provided
if all_params_provided:
    _complete_params_provided(state, feature)

# analyze.py 中的实现
def _complete_params_provided(state: VideoAgentState, feature: str):
    state["pending_question"] = None
    state["current_step"] = FEATURE_TO_STEP.get(feature, "execute_transform")
```

### 参数完整性检查

对于需要文件上传的功能（如 concat），需要在 UI 层面验证文件数量：

```python
elif feature == "concat":
    video_files = state.get("video_files", [])
    all_params_provided = len(video_files) >= 2
```

### 会话重置

在 `video_agent.py` 的 `process_video` 中，如有必要重置新功能相关状态：

```python
state["your_param"] = None
state["your_param_explicit"] = False
```
